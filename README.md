 Smartphone Usage & Digital Addiction

 Overview
This project analyzes smartphone usage patterns and digital addiction using **SQL and Power BI**.

 Objectives
- Analyze daily screen time and smartphone usage.
- Study social media, gaming, notifications, and app usage.
- Examine sleep and work/study patterns.
- Create an interactive Power BI dashboard.


- **SQL** – Database setup, data cleaning, and analysis
- **Power BI** – Data preparation, visualization, dashboard, and report development

project process
1. Collect and prepare the dataset.
2. Create database and analyze data using SQL.
3. Import and clean data in Power BI.
4. Create KPIs, charts, graphs, and filters.
5. Develop an interactive dashboard.
6. Perform performance testing.
7. Document and present the findings.

 Key Metrics
- Average Daily Screen Time
- Average Social Media Usage
- Average Gaming Hours
- Average Sleep Hours
- Average Notifications
- Average Weekend Screen Time
- Average Work/Study Hours
- Average App Opens

 Performance Testing
Check:
- Amount of data loaded
- Filter/slicer response
- Number of DAX calculations
- Number of visualizations

Conclusion
The project converts smartphone usage data into meaningful insights through **SQL analysis and Power BI visualization**, helping understand usage patterns and digital addiction indicators.
